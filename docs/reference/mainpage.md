# nova-os API reference

The C interface a program written for nova-os uses, generated by Doxygen
from the comments in its headers:

- the system calls, in native.h, and the numbers, rights and records they
  share with the kernel, in native_abi.h;
- the protocols that programs, services and drivers speak over channels,
  each in the header in `include/` named for it;
- the client library's headers, in `lib/`.

`include/` also holds what nova-boot and the kernel share: the boot
record, the virtual address space, paging, and the processor's
instructions as C functions.

A comment that cites a section, such as objects.md O5 or syscalls.md S7,
cites the specification in the repository's `docs/spec/`, which gives
each design and the reasons for it.
